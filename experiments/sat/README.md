# Unused SAT experiments

These sources are preserved from the initial submission commit, `003c728`.
They are not imported by the final proof and are kept outside the Lax proof
package so that submission validation does not compile them or launch their
SAT solvers.

The active proof uses the direct geometric arguments in
`proofs/Lax56Proofs/HKBDirectMc.lean` and its dependencies. The root module
`proofs/Lax56Proofs.lean` lists every active proof module.

The experimental source contents and original module names are unchanged.
This directory is an archive of experiments, not a standalone Lake package.
